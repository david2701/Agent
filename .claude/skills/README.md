# Skills del proyecto

Copias de [Taste Skill](https://github.com/Leonxlnx/taste-skill) (MIT, commit `717446e`)
usadas para el diseño del dashboard y como guía de criterio para la app.

- `taste-skill/` (design-taste-frontend v2): reglas anti-genéricas de tipografía, color, layout y movimiento.
- `minimalist-skill/`: lenguaje editorial sobrio.
- `redesign-skill/`: auditorías de rediseño.
- `output-skill/`: entregables completos, sin placeholders.

Nota: Taste declara fuera de alcance los dashboards densos y las apps nativas
(sección 13). Por eso el dashboard aplica sus reglas sobre tokens propios y la app
Android usa Material 3 Expressive como sistema base, con la misma paleta y tipografía.
